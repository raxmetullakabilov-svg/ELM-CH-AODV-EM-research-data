# Optional STEP 7.3C raw trace evidence

This directory is intentionally empty in the core GitHub release. The separately prepared `ELM_GITHUB_RAW_TRACE_ADDON_v1.0.zip` contains three pieces of the original 38.1 MB frozen input archive and a verified reconstruction script. Add the contents of that package here if raw packet-level independent reanalysis is to be supported.

Without the optional raw-trace add-on, the repository supports checking published run-level data, frozen statistics and script logic, **not** independent recomputation of FRPDR from source packet traces. Do not claim raw packet traces are shared if they have not been uploaded.
